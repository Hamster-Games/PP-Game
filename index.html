🌐 Multiplayer

Bis zu 8 Spieler können gemeinsam spielen. Mit dem Node-Server im Ordner server kannst du deine eigene IP-Adresse oder Domain verwenden. Sechsstellige Raumcodes nutzen weiterhin den öffentlichen PeerJS-Dienst.

Mit eigenem Server: Verwende die vom Server angezeigte Adresse und eine echte öffentliche IP oder Domain, deren DNS auf deinen Server zeigt. Beispieladressen aus Anleitungen funktionieren erst, wenn du sie durch deine echte Adresse ersetzt. Host und Gäste müssen dieselbe Adresse verwenden.
